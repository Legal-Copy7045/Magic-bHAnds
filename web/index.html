MagicBand Bridge

Firmware {{VERSION}} · ESP32-S3 · controls MagicBand+ lights & vibration from Home Assistant

1 Prepare the board

  • IPEX boards: click the antenna onto the board before powering it.
  • Plug it into this computer using the USB-C port labelled UART, with a data cable.
  • Use Chrome or Edge on a desktop. Safari and Firefox can't flash boards.

2 Install the firmware

Click Install and pick the serial port that appears when you plug the board in. When flashing finishes, enter your Wi-Fi details.

Your browser can't flash boards. Open this page in Chrome or Edge on a computer. This page must be opened over HTTPS.

Board not detected? Hold BOOT, tap RST, release BOOT, then try again.

3 Add it to Home Assistant

  1. Home Assistant shows a Discovered notification for “MagicBand Bridge” followed by a short code that's unique to the board. Click Add. If it doesn't appear, go to Settings → Devices & services → Add integration → ESPHome, and enter the board's IP address from your router.
  2. Open the device page, hold your band nearby, and press Test red buzz.

4 Make automations

Import the blueprint, then create “flash my MagicBand when…” automations without writing YAML.

Import blueprint

More coverage? Install more boards the same way. Automations send through all of them by default.
